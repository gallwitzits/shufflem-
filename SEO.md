Diese Datei enthält empfohlene Einstellungen, damit das öffentliche GitHub-Repository besser über GitHub Search und Google gefunden werden kann.


## Hinweise

- Die wichtigsten Keywords stehen natürlich formuliert in der `README.md`.
- Die GitHub Topics sollten zusätzlich manuell in der GitHub-About-Box gesetzt werden.
- Nach Änderungen kann es einige Tage bis Wochen dauern, bis Google die Seite neu indexiert.
- Ein sprechender Repository-Name ohne Sonderzeichen hilft ebenfalls. Falls möglich, wäre `shufflem` oder `wow-mythic-plus-discord-bot` suchfreundlicher als `shufflem-`.
